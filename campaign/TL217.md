# TL-217 live past-time grid

`examples/tl217_live_past_grid.rs` constructs 75 formula shapes: O, H, S and
T at `[0,0]`, `[0,1]`, `[0,2]`, `[1,1]`, `[1,2]`, and `[2,2]`, plus strong Y,
at nesting depths 1–3. Each shape runs on all-true, all-false and
boundary-toggle traces of six positions, for 1,350 per-step cells. The source
evaluator and independent `tl-oracle` are compared on every cell. Target
disagreement, absent target rows and mapping refusal are distinct outcomes.

The opt-in gate requires a clean mlTL source checkout and a clean R2U2 source
checkout at `336a2453dd2bd89bd26e9e45fb772a4bf77e4a6a`, including the
compiled monitor whose SHA-256 is pinned in the producer. It runs 21 fresh
C2PO/monitor pairs and independently reconciles 147 raw artifacts and all
1,350 rows. Set `PATH` so Cargo, rustc and Clippy are from Rust 1.98.1.

```sh
python3 campaign/tl217_grid_gate.py \
  --repo "$PWD" \
  --target-source /absolute/path/to/clean/r2u2 \
  --raw-dir /private/tmp/tl217-raw-new \
  --report /private/tmp/tl217-report-new.txt
python3 -m unittest discover -s campaign -p test_tl217_grid_gate.py
```

Both output paths must be unused. The gate writes the report even if the live
producer finds an admitted mismatch; its exit remains nonzero. Raw data is
retained outside Git. A passing result is scoped to the enumerated shapes,
three trace families, six positions and exact target executable. Target rows
outside those six input positions are counted separately and do not become
agreement credit.
