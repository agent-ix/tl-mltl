# V7 native robustness producer

`v7_native.py` runs three exact `thumbv7em-none-eabi` tl-syntax builds under
Rust 1.98.1 and eight selected host Miri tests under the recorded nightly.
The selected tests cover 34 reviewed at-limit/one-over pairs and three
additional typed refusal edges across the five Stage 1 crates. The report
retains every source revision, feature selection, command, raw log digest,
tool version, and excluded Miri path. A zero exit with no selected test is
incomplete, as is a missing build completion line.

Use five clean, distinct checkouts, the installed target, and a writable
`CARGO_HOME` with the locked registry packages and git pins provisioned. The
runner maps git dependency URLs to the supplied local checkouts and keeps
Cargo in offline mode while it runs probes. For example:

```sh
python3 campaign/v7_native.py \
  --syntax /Users/peter/dev/.worktrees/tl-syntax-v7 \
  --parse /Users/peter/dev/.worktrees/tl-parse-v7 \
  --mltl /Users/peter/dev/.worktrees/tl-mltl-v7 \
  --rewrite /Users/peter/dev/.worktrees/tl-rewrite-v7 \
  --oracle /Users/peter/dev/.worktrees/tl-oracle-v7 \
  --cargo-home /private/tmp/tl-v7-cargo-home \
  --raw-dir /private/tmp/tl-v7/embedded_miri_limits_native \
  --output /private/tmp/tl-v7/embedded_miri_limits_native.json
```

Keep the report and raw directory in this sibling layout. The independent
`v7_gate.verify` replay resolves the eleven logs relative to the report's
parent directory and refuses other layouts.

The pair counts are the assertions reviewed in the source tests at the
reported revisions; the runner does not infer them from Cargo's one-test
summary. This bounded sample does not establish that every public operation
has a limit pair. Other host and external-process paths remain listed as
not run under Miri. The embedded builds establish only tl-syntax's declared
`no_std` surface; no target execution or embedded claim is made for the
other four crates.
