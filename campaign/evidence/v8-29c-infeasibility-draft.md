- For `rewrite/src/infinite.rs:806`, the remaining proof obligation is exact pass termination, not merely the absence of a bounded counterexample. The following is an **independently audited proof candidate**, not an accepted infeasibility decision:
  1. Interpret every validated topologically ordered node as a finite *unfolded term*. Use a recursive path order with the strict precedence edges `Equivalent, Implies > Not >` each other Boolean/temporal constructor and leaf; `Until_i > Future_i`, `Release_i > Globally_i`, and `Once_[1,1] > StrongPrevious`. Interval values are preserved by all relevant rules. Treat each interval-decorated constructor as a distinct symbol, with different intervals incomparable except the explicit same-interval `Until_i > Future_i` and `Release_i > Globally_i` edges; leaves are below operators. This finite-rank partial precedence is well-founded. RPO has the subterm and context monotonicity properties needed below.
  2. Audit every `Pass::apply` rule alternative at `src/infinite.rs:167–416`: Boolean constant, idempotence and double-negation branches return a subterm or leaf; Implies elimination emits `Not(left)` and `Or(Not(left), right)`, both strictly below `Implies(left,right)`; Equivalent false arms emit `Not` of a child, below Equivalent. Each Not temporal dual emits only negated proper children and a temporal parent, all strictly below the old `Not(temporal(...))`; the Since fold emits `Triggered(p,q)` below `Not(Since(Not(p),Not(q)))`. Singleton F/G/U/R branches return a subterm; constant F/G return leaves; U true-left emits `Future_i(right)`, R false-left emits `Globally_i(right)`, and Once previous emits `StrongPrevious(operand)`, each strictly below its old constructor.   3. In one successful pass (`:657–739`), process source nodes in topological order. The already mapped operand terms are no greater than their old terms by induction. `remap` only rebuilds the old constructor around those operands, so the remapped kind is no greater than the old unfolded term. Charge each *new* `Pass::emit` allocation to the source node whose `apply` or unchanged-path `emit` requested it (`:130–153`, `:663–703`). Under step 2, a rule's helper and replacement allocations are each strictly smaller than that source node's old term. A no-rule allocation is no greater, and is strictly smaller if an operand decreased. Interned returns allocate nothing; operand-return rules allocate nothing for that source. One old term may thus be replaced by any finite multiset of strictly smaller terms, or by one non-greater term. This is the standard well-founded multiset extension of the RPO.
  4. `compact` (`:515–568`) visits from formula root plus *all* fairness roots and only deletes raw emitted nodes; renumbering preserves each unfolded term. It cannot add a term. Therefore the multiset of all graph-node terms cannot increase from current to candidate. It strictly decreases if any source node fires a rule, any operand decreases, any source node interns into another allocation, or compaction drops a node.
