# The shared assurance lane (FR-006). Install this in its OWN environment.
#
# It is deliberately separate from the system interpreter. Nothing in this
# repository imports jsonschema once the local evidence machinery is gone — the
# Draft 7 lane belonged to schemas/ and the collector, both of which this
# migration retires — so there is no version conflict left to resolve. The
# environment exists for a different reason: engineering-assurance is pinned as a
# git tag, and resolving a git dependency into the system interpreter would make
# the pin depend on whatever else that interpreter happens to have.
#
# The pin is the accepted release from agent-ix/engineering-assurance#8, which
# publishes engineering-assurance as a source distribution: the git tag IS the
# released artifact. It is not a branch head and must not be replaced by one.
engineering-assurance @ git+https://github.com/agent-ix/engineering-assurance@v0.2.0
