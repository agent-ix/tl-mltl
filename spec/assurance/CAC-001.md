# tl-mltl semantic oracle contract

## Component Boundary

The component begins with an already validated tl-syntax Formula plus an
ordered trace and ends with a typed report or explicit error. Parsing and
external execution remain outside.

## Required Behavior

The core returns only values justified by the named profile and complete input.
Closed evaluation, prefix evaluation, and horizon analysis agree at decision
boundaries. Unsupported mapping or external-tool failure cannot become a pass.

## Failure Handling

Profile mismatch, malformed traces, overflow, work-budget exhaustion, and
unsupported mapping return distinct errors. No fallback Boolean is emitted.

## Controls

Checked horizon arithmetic, configured work/span budgets, and a fixed
recursion-depth boundary gate temporal expansion. Versioned schemas, source
pins, and content digests gate exchange.

## Replacement

A replacement must pass the same shared and differential corpus, retain exact
identity fields, and demonstrate that arithmetic and work limits fail closed.
