# tl-mltl v0.1 conformance evidence plan

## Decision Use

Evidence informs only the human source-release decision. It does not itself
approve, certify, accredit, or publish a release.

## Population

The population is every matrix criterion, public operator, boundary case,
checked-in corpus fixture, CLI schema, and declared supported differential case.

## Collection Procedure

Record complete CI, specification validation and coverage, shared-corpus
evaluation/horizons, deterministic CLI output, adapter mapping, differential
comparison, code review, and gap analysis against one revision. Retain command,
tool/dependency identity, output, limitation, status, and SHA-256 checksums in a
canonical PGM-01 envelope.

## Interpretation

Local and differential success support only the exercised cases. Missing R2U2
execution is `unsupported` or `skipped`, never agreement. Automation cannot
approve, certify, accredit, or publish a source release.
